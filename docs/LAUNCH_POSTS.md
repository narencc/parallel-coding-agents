## Developer-focused post

> All five AI solutions passed our original tests. Extra checks found bugs in two.
>
> I gave the same money-converter assignment to five GPT models. All five passed
> the original 44 checks. Code review suggested 22 additional checks; two answers
> failed five of them, revealing long-input and whitespace problems.
>
> The repository includes every saved draft, final answer, original test, review
> case, and recorded cost estimate. You can browse the evidence without a key or
> play a local text replay without installing the OpenAI package.
>
> This is one task and one run, not a model ranking. The top three tied on checks;
> readability decided which answer we kept.
>
> Can you find a valid input the kept answer handles incorrectly?
>
> [Explore the project](https://github.com/narencc/parallel-coding-agents)
